## 当前前端第三方组件核查

[`new_frontend/package.json`](../new_frontend/package.json) 已安装 `@assistant-ui/react`、Radix Dialog/Dropdown Menu/Popover/Slot/Tabs/Tooltip、TanStack Query、Lucide、react-dropzone、react-resizable-panels、Zustand 等。实际产品源码中，[Dropdown Menu](../new_frontend/src/features/chat/Composer.tsx)、[Tabs](../new_frontend/src/features/chat/AgentPanel.tsx)、[Query](../new_frontend/src/features/workspace/WorkspacePage.tsx)、[拖拽上传](../new_frontend/src/features/chat/Composer.tsx)、[分栏](../new_frontend/src/features/workspace/WorkspacePage.tsx)和 Lucide 已使用；`@assistant-ui/react`、Dialog、Popover、Tooltip、Slot 在 `src` 的非测试代码里尚无导入。这回答了“是否已经用了很多开源 React 组件”：**依赖装了不少，现有界面真正使用的只是一部分**。设计实施时优先复用已安装且合适的 Radix 原语和 Lucide；对话框、菜单、提示可补齐现有组件封装，减少自行重写的键盘与焦点逻辑。

现有[会话 CSS](../new_frontend/src/styles/sidebar.css)将 hover 和 active 写成绿色，且[侧栏](../new_frontend/src/features/workspace/ProjectSidebar.tsx)把项目和会话分为两段。重构时先将其改为统一灰阶语义变量、嵌套的项目与会话关系，并让选中对话的整行灰色背景在深浅主题中都清晰可见。以上是基于本地源码与用户提供的截图作出的 PSKit 设计建议，不是两个参考项目对 PSKit 的要求。
