# 新后端完整落地执行清单

## 目标和验收边界

把 `new_backend/` 从 Mock 演示服务推进为可接真实身份、模型网关、MCP 和 AF3 计算资源的科研 Agent 后端；保持 `new_frontend/` 只调用版本化 Python API。Pi 负责推理与工具循环，Python 负责身份、授权、配额、任务、文件、事件和恢复。旧 `backend/` 保持独立，不直接导入其内部模块。

每一片先在公开 HTTP/API 事件边界写失败测试，再写最小实现；更新 OpenAPI、前端类型和操作文档。外部服务使用契约替身测试，最后必须用真实凭据和计算节点做联调，不能把替身测试标为真实接入。

## 当前验证快照（2026-10-02）

- `new_backend`: 非沙箱执行 `python -m pytest -q`，274 个测试通过；沙箱内的 PDF 与 Pi 子进程退出用例可能卡住，已在非沙箱复核。
- `new_frontend`: `npm run typecheck`、`npm run lint`、`npm run test`（106 个测试）和 `npm run build` 通过；`node --test pi/extension.test.js` 在上一轮通过。Vitest 默认多进程运行出现跨页面 5 秒超时，同一代码限为 2 个 worker 后两次全通过，已把上限固定在 `vite.config.ts`。并行前端改动仍通过 Python API，未发现新的浏览器本地 mock 接口。
- 后端 Ruff 尚未执行：当前 Python 环境未安装，`uv` 的隔离缓存可用但当前网络无法获取开发依赖。真实 Supabase、模型网关、MCP 和 AF3 节点仍未联调。
